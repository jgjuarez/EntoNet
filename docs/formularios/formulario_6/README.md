# Formulario 6

Documentacion operativa para el formulario de crianza y conteo de adultos.

Archivos:

- `00_resumen.md`: objetivo, alcance y estado.
- `01_estructura.md`: secciones, campos, validaciones y relaciones.
- `02_consultas.sql`: consultas de control y validacion.
- `03_soluciones.md`: decisiones tecnicas aplicadas.
- `04_estilos.md`: patrones visuales y de captura.
- `05_cambios.md`: historial de cambios.
- `06_mapeo_ui.md`: controles previstos para captura guiada.

Archivos relacionados:

- `base_datos_entonet/formulario_6_crianza_conteo_adultos.csv`
- `base_datos_entonet/diccionario_formulario_6.csv`
- `base_datos_entonet/listas_validacion_formulario_6.csv`
