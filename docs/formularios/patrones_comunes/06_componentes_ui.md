# Componentes UI

## Componentes repetibles

- `alert alert-info` para instrucciones
- `alert alert-success` para resultado exitoso
- `alert alert-warning` para validaciones y alertas
- `submit-row` para acciones principales
- `wellPanel` para agrupacion de secciones
- `tabsetPanel` para formularios largos
- `conditionalPanel` para campos dependientes
- `dateInput`, `numericInput`, `textInput`, `textAreaInput`, `selectInput`
- `actionButton` para avanzar, buscar, guardar o imprimir

## Regla reutilizable

- Toda pantalla larga necesita una jerarquia clara.
- Todo campo dependiente debe aparecer y desaparecer sin romper el flujo.
- Todo formulario debe tener una accion principal visible al final.
