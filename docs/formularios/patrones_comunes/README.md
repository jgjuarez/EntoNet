# Patrones comunes de formularios EntoNet

Este directorio reúne reglas reutilizables para reconstruir formularios nuevos
sin repetir decisiones ya resueltas en Formulario 1, 5 y 7.

## Que guarda este bloque

- Navegacion por pasos
- Estados de captura y revision
- Bloques de metadatos
- Bloques de identificacion territorial
- Validaciones recurrentes
- Patrones de impresion
- Patrones de guardado y revision

## Uso recomendado

1. Consultar este bloque antes de crear un nuevo formulario.
2. Reutilizar los patrones que ya aparecen en los formularios existentes.
3. Documentar aqui cualquier decision que deba repetirse en otro proyecto.
