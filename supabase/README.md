# Supabase EntoNet

Este directorio guarda scripts y notas para montar la base de datos de captura en Supabase.

Orden sugerido de ejecucion:

1. `001_formulario_5_flat.sql`
2. Scripts futuros de catalogos, permisos y vistas.

La tabla inicial es plana para facilitar la importacion del CSV. Luego se puede normalizar cuando ya esten definidos todos los formularios.
